# React Todo App - Frontend Geliştirme Projesi

Bu proje, modern web geliştirme standartlarına uygun olarak **React** ve **Vite** kullanılarak geliştirilmiş kapsamlı bir yapılacaklar listesi (Todo App) uygulamasıdır.

## Canlı Önizleme

Projenin canlı haline aşağıdan ulaşabilirsiniz:
👉 [**Netlify Canlı Uygulama Linki Buraya Gelecek**](https://senin-netlify-linkin.netlify.app)

## Özellikler (CRUD)

Proje, bir web uygulamasının temelini oluşturan tüm CRUD işlemlerini içermektedir:

- **Create (Ekleme):** Yeni görevler eklenebilir.
- **Read (Listeleme):** Eklenen görevler anlık olarak listelenir.
- **Update (Güncelleme):** Görevlerin durumu (tamamlandı/devam ediyor) değiştirilebilir ve çift tıklama ile görev metni düzenlenebilir.
- **Delete (Silme):** Görevler listeden kaldırılabilir.

## Kullanılan Teknolojiler

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** Pure CSS (Modern UI)
- **Deployment:** [Netlify](https://www.netlify.com/)

## 📂 Proje Yapısı

Eğitim yönergesine uygun olarak aşağıdaki klasör mimarisi takip edilmiştir:

```text
src/
├── Components/    # Tekrar kullanılabilir arayüz bileşenleri (Form, List)
├── Pages/         # Ana uygulama sayfası (App.jsx)
├── Interfaces/    # Veri yapıları ve tip tanımlamaları (Klasör yapısı kuralı)

```
